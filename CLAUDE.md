
** Este projeto é relacionado ao desenvolvimento de uma Landing Page para captação de leads.

** A LP deverá conter uma página de chat para captação de leads.

** O chat deverá ser integrado com o Bitrix24 para captação de leads.

** O chat deverá ser equipado para os seguintes procedimentos:

- Autor
- Associado
- Advogado

** O chat deverá ter as seguintes etapas:

- Qualificação (Extrai Nome e Celular do usuário, é orientado a isso e só deve liberar a calculadora apenas após a extração )
- Calculadora (Calcula o valor do precatório)
- Captação de Lead 

** A LP deverá ter as seguintes etapas:

- Hero
- Vantagens
- Depoimentos
- Perguntas Frequentes
- Formulário
- Footer
